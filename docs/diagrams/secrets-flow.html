Secrets Flow — AWS Secrets Manager → Pods

1 · Terraform creates placeholders in AWS Secrets Manager

idp-mvp/backstage→GitHub token + OAuth app, session secrets, Postgres, Kubernetes SA token, PagerDuty / Jira, Datadog keys idp-mvp/dora-exporter→GITHUB_TOKEN idp-mvp/kagent→ANTHROPIC_API_KEY (and LITELLM_MASTER_KEY) idp-mvp/litellm→DATABASE_URL idp-mvp/slack-webhook→SLACK_WEBHOOK_URL

2 · bootstrap.sh injects real values from local/.env and the cluster

K8S_SERVICE_ACCOUNT_TOKEN←kubectl get secret backstage-sa-token BACKSTAGE_CATALOG_TOKEN←generated random value GITHUB_TOKEN←read from the environment GITHUB_APP_*←GitHub App (optional; replaces the PAT) TEAM_MAP←optional JSON repo→team map for DORA metrics

3 · External Secrets Operator reads via IRSA

  • ClusterSecretStore aws-secretsmanager — usable from every namespace; IRSA via external-secrets-sa; reads only idp-mvp/dora-exporter
  • SecretStore aws-secrets-manager (namespace backstage) — IRSA via the backstage service account
  • SecretStore (namespace ml-platform) — IRSA via litellm-eso-sa
ExternalSecret per namespace
  • backstage-secrets (backstage) → idp-mvp/backstage
  • dora-exporter-secret (monitoring) → idp-mvp/dora-exporter via the ClusterSecretStore
  • LiteLLM secrets (ml-platform) → idp-mvp/kagent, idp-mvp/litellm
syncs every 1 h (or on the force-sync annotation)
