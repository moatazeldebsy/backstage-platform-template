Local Setup (Kind)

Run the full platform on your laptop. No AWS account needed.

Prerequisites​

brew install kind kubectl helm docker
kind version    # >= 0.27
helm version    # >= 3.14
docker info     # Docker running

The cluster is pinned to Kubernetes 1.33.1 (kindest/node:v1.33.1). Rancher Desktop also works: disable Traefik, use the dockerd engine, and set KUBERNETES_PROVIDER=rancher-desktop in local/.env.

VM sizing​

Set this in Docker Desktop → Settings → Resources (or Rancher Desktop → Virtual Machine). The VM gets about 80% of physical RAM.

SetupVM CPUVM memoryPhysical RAM
Everything816 GB24 GB
Full stack without Langfuse (--skip-langfuse)813 GB16 GB
Core + one AI component813 GB16 GB
Without AI/ML48 GB12 GB
Core only (--skip-obs --skip-policies)26 GB8 GB

A 16 GB Mac can't run the full platform. Install a subset instead. kubectl get nodes reports the whole VM against each Kind node, so two nodes on a 12 GB VM look like 24 GB; they aren't.

Warning signs: watch available memory (docker exec idp-mvp-worker free -m). Below ~1.5 GB, stop adding components; below ~200 MB, etcd and the API server time out and every *.idp.local URL fails. Sustained CPU above ~75% of the VM leaves pods stuck in Terminating and controllers crash-looping on liveness probes. CPU is the limit during install, memory at rest, so install incrementally on a tight machine.

Running on less​

./scripts/bootstrap-local.sh                         # skip bootstrap-ai.sh entirely: saves ~3.2 GB
./scripts/bootstrap-ai.sh --skip-langfuse            # the most expensive AI piece: saves ~2.2 GB
./scripts/bootstrap-ai.sh --agents idp               # one agent pod (--agents list, all, none)
./scripts/bootstrap-local.sh --skip-obs              # no metrics stack: saves ~1.6 GB (Grafana/DORA/FinOps tabs go blank)
./scripts/bootstrap-local.sh --skip-policies         # no Kyverno/Gatekeeper: saves ~0.6 GB
./scripts/bootstrap-local.sh --skip-obs --skip-policies --skip-dora   # leanest: Backstage + ArgoCD + hello-service

bootstrap-ai.sh installs six agents by default (idp, qa, release, cost, platform, contract); incident, security and onboarding need --agents all or an explicit list. --agents prunes: re-running with a shorter list removes the others. If memory is tight, drop Langfuse before LiteLLM — without LiteLLM, agents can call tools but get no model replies.

Loki and Tempo ship disabled​

They run zero pods locally because a single-node Kind cluster already overcommits CPU, and adding them starves the control plane. To enable them, give the VM more resources first, then:

ComponentWhereChange
Tempolocal/observability/tempo/tempo-values.yamlreplicas: 0 → 1
Promtaillocal/observability/loki/promtail-values.yamldelete the nodeSelector: {idp/disabled} block
Lokiscripts/bootstrap-local.sh (step 5c)remove the kubectl scale statefulset loki --replicas=0 line

Bootstrap (~10–15 min)​

First time, run only setup.sh and choose "local":

./scripts/setup.sh

It personalises the placeholders, creates the .env files, runs bootstrap-local.sh and offers to start Backstage. Use bootstrap-local.sh directly only for day-2 work, such as recreating the cluster after --destroy:

./scripts/bootstrap-local.sh                  # cluster + platform
./scripts/bootstrap-local.sh --full           # + Backstage in one go
./scripts/bootstrap-local.sh --start-backstage

It creates a local registry (localhost:5003), the Kind cluster, namespaces and RBAC, nginx ingress, metrics-server, Prometheus/Grafana/Alertmanager, OpenCost, ArgoCD, Gatekeeper and Kyverno, the Pushgateway and exporter CronJobs, and the idp-services ApplicationSet, which deploys hello-service, idp-mcp-server and qa-mcp-server to services-dev. It also writes the *.idp.local entries to /etc/hosts. All flags are in the Scripts Reference.

Environment files​

setup.sh creates both from their .env.example files:

FileFill in
local/.envGITHUB_TOKEN; for AI, ANTHROPIC_API_KEY (and optionally OPENAI_API_KEY)
local/backstage/.envAUTH_GITHUB_CLIENT_ID, AUTH_GITHUB_CLIENT_SECRET for GitHub sign-in

K8S_*, ARGOCD_AUTH_TOKEN and GRAFANA_TOKEN are filled in by the bootstrap.

Start Backstage​

./scripts/bootstrap-local.sh --start-backstage

Builds the image, starts Docker Compose, wires the ingress to the container, triggers a catalog export and prints every URL. Open http://backstage.idp.local (not localhost:3000 — GitHub sign-in only works on the configured base URL).

After changing code under backstage/app/packages/, run the same command again; config-only changes need just docker compose -f local/backstage/docker-compose.yml restart backstage. If you restart Docker Compose yourself, --update-backstage-ip rewires the ingress.

Deploy a service​

Scaffold one from Create in Backstage (or with idp scaffold service --name my-svc --type nodejs; add --local to generate offline). Merged GitOps changes are deployed by ArgoCD.

To deploy an image by hand, push it to the local registry and run the Deploy Service to local Kind cluster template, or:

docker build -t localhost:5003/<name>:latest services/<name> && docker push localhost:5003/<name>:latest
helm upgrade --install <name> ./helm/service-template -n services --create-namespace \
  --set image.repository=localhost:5003/<name> --set image.tag=latest \
  --values services/<name>/helm-values-local.yaml

AI/ML stack (optional)​

./scripts/bootstrap-ai.sh   # needs ANTHROPIC_API_KEY in local/.env

Installs KAgent and its agents, the eight MCP servers behind the AI Gateway, LiteLLM, Langfuse, MLflow and Argo Workflows. Then restart Backstage (--start-backstage) to reveal the AI pages. Skip flags and agent selection are covered above and in the Scripts Reference; usage is in AI Assistant. Remove just the AI layer with ./scripts/bootstrap-ai.sh --destroy.

Teardown​

./scripts/bootstrap-local.sh --destroy

In order: removes the AI layer, cleans up scaffolded services (deletes their ArgoCD apps and Helm releases, removes services/<name>/ and commits), deletes the cluster, stops and prunes the Docker Compose stack, and removes the /etc/hosts entries. kubernetes/teams/, scaffolded GitHub repos and test-suites/ are left alone.
