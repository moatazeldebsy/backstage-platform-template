# JVM (Java/Spring Boot) Service

Scaffold a Java Spring Boot service with Gradle, CI/CD, and Helm deployment

## How to use

1. Open Backstage → **Create**
2. Find **JVM (Java/Spring Boot) Service** and click **Choose**
3. Fill in the required parameters and click **Create**

## When to use this template

This is the golden path for **new, greenfield microservices** run by small autonomous teams that prefer the
JVM ecosystem, and for extracting performance- or concurrency-sensitive modules out of the monolith into a
JVM runtime.
