# Kubernetes Cluster (EKS)

Provision an EKS cluster with autoscaling node groups and platform addons (ingress-nginx, cert-manager, ArgoCD, Prometheus).

## How to use

1. Open Backstage → **Create**
2. Find **Kubernetes Cluster (EKS)** and click **Choose**
3. Fill in the required parameters and click **Create**
