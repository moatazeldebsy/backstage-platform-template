# Model Serving API

Deploy an ML model as a REST API using Ollama (local) or vLLM (AWS). Serve open-source LLMs for inference with auto-scaling and health probes.

## How to use

1. Open Backstage → **Create**
2. Find **Model Serving API** and click **Choose**
3. Fill in the required parameters and click **Create**
