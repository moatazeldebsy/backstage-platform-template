# S3 Object Bucket

Create an S3 bucket with versioning, lifecycle rules, KMS encryption, and a least-privilege IAM policy attached to the requesting service.

## How to use

1. Open Backstage → **Create**
2. Find **S3 Object Bucket** and click **Choose**
3. Fill in the required parameters and click **Create**
