# OWASP ZAP DAST Security Scan

Scaffold an OWASP ZAP dynamic application security test suite with baseline and full-scan modes

## How to use

1. Open Backstage → **Create**
2. Find **OWASP ZAP DAST Security Scan** and click **Choose**
3. Fill in the required parameters and click **Create**
