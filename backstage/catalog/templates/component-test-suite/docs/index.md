# Component Test Suite (mocked deps)

Test a single service end-to-end with its external HTTP dependencies stubbed by WireMock. Faster than Testcontainers, more realistic than unit tests.

## How to use

1. Open Backstage → **Create**
2. Find **Component Test Suite (mocked deps)** and click **Choose**
3. Fill in the required parameters and click **Create**
