# Accessibility (a11y) Test Suite

Scaffold an axe-core + Playwright accessibility test suite enforcing WCAG compliance on every PR

## How to use

1. Open Backstage → **Create**
2. Find **Accessibility (a11y) Test Suite** and click **Choose**
3. Fill in the required parameters and click **Create**
