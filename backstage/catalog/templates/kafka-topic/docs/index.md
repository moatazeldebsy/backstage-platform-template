# Kafka Topic

Create a Kafka topic on the shared MSK cluster with partitions, retention, ACLs for the owning service, and an optional schema registry subject.

## How to use

1. Open Backstage → **Create**
2. Find **Kafka Topic** and click **Choose**
3. Fill in the required parameters and click **Create**
