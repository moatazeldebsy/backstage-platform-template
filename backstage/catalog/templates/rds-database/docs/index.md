# Managed Postgres (RDS)

Spin up an Amazon RDS Postgres instance with multi-AZ failover, automated backups, and IAM auth. Credentials are written to the requesting service namespace as a secret.

## How to use

1. Open Backstage → **Create**
2. Find **Managed Postgres (RDS)** and click **Choose**
3. Fill in the required parameters and click **Create**
