# Testcontainers Integration Test Suite

Scaffold a Testcontainers integration test suite that spins up real dependencies (DB, cache, queues) in CI

## How to use

1. Open Backstage → **Create**
2. Find **Testcontainers Integration Test Suite** and click **Choose**
3. Fill in the required parameters and click **Create**
