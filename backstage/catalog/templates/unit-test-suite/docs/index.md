# Unit Test Suite (brownfield)

Add a standardized unit-test scaffold + coverage gate (70%) + JUnit output to an existing service repo. Language-aware (Go, Node/TS, Python).

## How to use

1. Open Backstage → **Create**
2. Find **Unit Test Suite (brownfield)** and click **Choose**
3. Fill in the required parameters and click **Create**
