# IaC Test Suite (Terraform)

Add tflint + Checkov (policy/security) + Terratest (real-apply) to an existing Terraform repo. Catches misconfigs before they ship.

## How to use

1. Open Backstage → **Create**
2. Find **IaC Test Suite (Terraform)** and click **Choose**
3. Fill in the required parameters and click **Create**
