Engineering Intelligence — Roadmap

All fourteen planned phases (0–13) have shipped. This page lists what each one delivered and the known limits and debt that remain.

What shipped​

Known limits​

  • Model quality and architecture are never scored. Accuracy on an unknown dataset says nothing about production readiness, and architecture is a judgement.
  • Unmeasured areas are excluded, not zeroed. An untested risk is unknown, not absent.
  • Evaluation scores need a reachable Langfuse. A GitHub-hosted runner can't see an in-cluster one, so most installs report no scores and say why.
  • Review latency isn't collected (it needs a per-PR API call).
  • No saving figures are offered anywhere: nothing measures workload complexity.
  • Trends need two snapshots. There is no back-fill.
